# Current publication figures

This directory contains only the latest 18-figure white-background release.

- `png/`: high-resolution raster output.
- `svg/`: editable vector output.
- `pdf/`: publication PDF output.

The three formats are generated from the same frozen datasets. Scientific calculations are not performed inside plotting code. Hashes and QA records are stored under `manifests/figure_release/`.

Requested final layout changes are included: Figure 9(f) and Figure 16(d) are removed, and the small annotation in Figure 11(a) is removed.
